CoatField Inspector v1.0

Deploy all files to any HTTPS static host (GitHub Pages, Netlify, etc.). Open the URL on Android Chrome and choose Install app/Add to Home screen. Offline mode works after the first online visit. You can also open index.html locally for basic testing, but PWA installation and service worker require HTTPS or localhost.

Features: dew point, WFT, mixing by volume, paint consumption, local inspection records with compressed photos, print/save PDF, CSV and JSON backup/import.

IMPORTANT: Inspector must determine acceptance against approved project specifications, coating TDS and standards. Calculations are informational, not compliance certification. Device browser data can be erased; export backups frequently.

Version 1.1 adds TDS search and saved official document links. Direct PDF download depends on manufacturer website.
